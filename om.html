How to Use O&M Manual Generation
  1. Upload PDFs using Choose Files or by dragging and dropping files into the upload area. You can also use Import Submittal PDF to pull sections from a completed submittal. Do not include a cover page or table of contents - these are generated automatically.
  2. Name files with section keywords so they are detected automatically: warranty, warning, safety, emergency shutdown, maintenance, sequence of operations, testing checklist, parts list, datasheet or spec, control panel, electrical schematic, shop drawing, manual, and appendix.
  3. Verify each PDF is assigned to the correct section, then use Rename File to change how it appears in the Table of Contents.
  4. Use Format TOC on any non-warranty PDF to add sections and subsections. Section rows become main TOC entries; subsection rows appear indented under them.
  5. Enter the Project Number, Project Name, Project Address, System Name, and Revision. The warranty prompt appears before every build so you can use an uploaded warranty or generate a new warranty sheet.
  6. Click Build PDF to generate the final O&M manual.

Notes:

  • Imported submittal TOCs can use bullet rows for sections and dash rows for subsections.
  • Use Manage PDF to remove pages from warranty documents.
  • Datasheets can be reordered before building the PDF.
  • Files without a recognized keyword default to Datasheets.

Converter

Convert part numbers, item codes, and other PDF values using Excel cross-reference files.

How to Use Converter
  1. Drop in or choose a PDF such as a submittal, O&M manual, or datasheet.
  2. Drop in or choose an Excel file with Old Part # and either Item Code or New Part #.
  3. Click Preview Changes to scan the PDF.
  4. Drawing-style pages are OCR scanned when normal PDF text is not available.
  5. Click Preview PDF to visually compare the original and converted PDF.
  6. Click Build Converted PDF to download the updated PDF.

Submittal Automation

Generate submittal packets automatically.

How to Use Submittal Automation
  1. Upload PDFs using Choose Files or by dragging and dropping files into the upload area. Do not include a cover page or table of contents - these are generated automatically.
  2. Name files with section keywords so they are detected automatically: warranty, datasheet or spec, control panel, shop drawing or drawing, appendix, and revision remarks. Files without a recognized keyword default to Datasheets.
  3. Verify each PDF is assigned to the correct section, then use Rename File to change how it appears in the Table of Contents.
  4. Use Format TOC for Datasheets, Control Panel Components, Electrical Schematics, and Shop Drawings. Section rows become main TOC entries; subsection rows appear indented under them.
  5. Enter the Project Number, Project Name, Project Address, System Name, and Revision. The warranty prompt appears before every build so you can use an uploaded warranty or generate a new warranty sheet.
  6. Click Build PDF to generate the final submittal.

Notes:

  • Use Manage PDF to remove pages from non-subsection documents.
  • Revision Remarks are not numbered and do not appear in the TOC.
  • Datasheets can be reordered before building the PDF.
  • Imported submittal TOCs can use bullet rows for sections and dash rows for subsections.

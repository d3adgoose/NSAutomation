Submittal Automation

Generate submittal packets automatically.

How to Use Submittal Automation
  1. Upload PDFs using the Choose Files button or by dragging and dropping files into the upload area. Do not include a cover page or table of contents - these will be generated automatically. PDFs should be named according to the conventions outlined in the documentation.
  2. Verify each PDF is assigned to the correct section (Warranty, Datasheets, Control Panel Components, Shop Drawings, etc.).
  3. Use Edit TOC Sections to rename how a document appears in the Table of Contents.
  4. Use Format TOC to add individual tabs from Datasheets or Control Panel Components into the TOC.
  5. Enter the Project Number, Project Name, Project Address, System Name, and Revision.
  6. Click Build PDF Packet to generate the final submittal.

Notes:

  • Files are detected based on pdf naming conventions.
  • Revision Remarks are not numbered and do not appear in the TOC.
  • Datasheets can be reordered before generating the packet.
  • Subsections for Warranty automatically appear beneath their parent document in the TOC.

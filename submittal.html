Submittal Automation

Generate submittal packets automatically.

How to Use Submittal Automation
  1. Upload PDFs using Choose PDFs or by dragging and dropping files into the upload area. Do not include a cover page or table of contents - these are generated automatically.
  2. Name files with section keywords so they are detected automatically: warranty, datasheet or spec, control panel, shop drawing or drawing, appendix, and revision remarks. Files without a recognized keyword default to Datasheets.
  3. Verify each PDF is assigned to the correct Roman Section, then use Rename File to change how it appears in the Table of Contents. Use Undo and Redo to step back through pre-build changes.
  4. Use Format Levels to review scanned entries in a tree, add Level 0, Level 1, and Level 2 rows, choose parent rows, assign PDF pages, and remove unwanted rows or pages.
  5. Use Template inside Format Levels to add common level names. Template rows start with blank pages, so add a page to each row marked Template page required or remove that row before closing Format Levels.
  6. Enter the Project Number, Project Name, Project Address, System Name, and Revision. The warranty prompt appears before every build so you can use an uploaded warranty or generate a new warranty sheet.
  7. Click Build PDF, review the full PDF preview, then choose Build PDF to download or Edit to return to the builder.

Notes:

  • Revision Remarks are not numbered and do not appear in the TOC.
  • Sections with multiple included PDFs can be reordered before building.
  • Normal PDF page numbers account for generated TOC pages automatically.

How to Use Parts Library
  1. Import files: drop one or more drawing PDFs or Excel part lists, review the rows, then import the selected rows.
  2. Select rows: use the checkboxes beside each row, or use Select All above the table when you want the full visible list.
  3. Find records: search by part number, description, drawing, or file name, then sort the visible list with the Sort dropdown.
  4. Track usage: Current Parts stores the part list, Old Part Numbers stores prior numbers, and Drawing Usage shows where parts were found.
  5. Review Items to Check: Found values are read from the imported file. Suggested Current values are the closest existing Current Part the library found. Higher confidence means a stronger suggested match. Create a new part when the found number is truly new, or save the suggested number when the found number should become an old-number reference to that current part.
  6. Same number, different wording: the library keeps one part row, adds each new file name on its own line, and saves each description on its own line so either wording can be searched.
  7. Export: download the library to Excel when you need a backup or want to review the list outside the website.

Peer Review

Find potential drawing-package inconsistencies with local visual AI, OCR, and rule checks.

How to Use Peer Review
  1. Sign in through Database. Peer Review uses the same company login and Local AI connection as Specification.
  2. Check the Local AI indicator. If it is offline, open it and select Try Reconnecting.
  3. Select Start Overall Peer Review. The review independently checks the clean original for drawing quality, naming, title blocks, equipment quantities and callouts, dimensions, and visible coordination issues.
  4. Drop in or choose one engineering PDF. OCR reads image-only title blocks, and Local AI visually reviews enlarged drawing regions.
  5. Select Run Automatic Checks or Validate. Keep this page open while the timer and activity messages show the current step.
  6. Review every finding using its confidence or Rule Check label, page preview, comments, and status.
  7. Use the Fix List to track unresolved work, then save or export the review. Local History keeps the latest five reviews when browser storage allows.
One-time computer setup

Complete these steps once on each Windows computer that will analyze drawings.

  1. Install Ollama for Windows. Use its normal Windows installer.
  2. Install the LTS version from the Node.js download page. Keep the normal installation choices.
  3. Open d3adgoose/NSAutomation on GitHub. Select the green Code button, then Download ZIP.
  4. Open the downloaded ZIP file, select Extract all, and save the extracted folder somewhere permanent, such as Documents. Local AI needs this folder to stay in that location.
  5. Open the extracted NSAutomation folder and double-click Set Up NS Local AI.cmd. If Windows asks for confirmation, confirm only after checking that the file came from the repository linked above. Setup will try to approve the N/S website automatically; on managed computers it safely continues with manual Chrome permission instead.
  6. Leave the setup window open while it downloads the approved Qwen model. The first download is large and may take a while. Wait until it says Local AI setup is complete.
  7. Close and reopen Chrome, open this website, and select Log in. Sign in with your normal company account.
  8. Open the Local AI popup and select Try Reconnecting. If a Chrome permission question still appears, select Allow. Drawing files remain local.

After setup: select the Local AI status button. A green circle means the service and model are ready. You do not need to run the setup file again each day.

Local AI popup: follow the displayed Your next step message. Use Try Reconnecting after correcting an issue, or Close to return to Peer Review.

Using Local AI for Peer Review

Upload the clean original engineering PDF and select Run Automatic Checks or Validate. OCR reads image-only title blocks, while the approved local Qwen model independently reviews enlarged drawing regions, equipment tables, quantities, callouts, dimensions, and notes. Existing reviewer annotations are not required. Keep the page open until the activity message says the automatic review is complete.

Every result remains pending until you review it. Confidence shows the model's certainty, while Rule Check identifies a direct comparison performed without AI judgment.

Important: Peer Review identifies potential visible inconsistencies. It does not certify the design or replace an engineer's final review.

Start an Overall Peer Review

Upload the clean original drawing. The review creates proposed findings by checking drawing quality, quantities, dimensions, title blocks, equipment tables, callouts, and visible coordination issues.

How to Use Peer Review
  1. Sign in through Database. Peer Review uses the same company login and Local AI connection as Specification.
  2. Confirm Local AI Ready. Select the Local AI indicator to check the background service and model. Use Try Reconnecting if needed.
  3. Choose a review type. Initial Review checks the drawing package broadly. Equipment Review also compares the formal equipment list and drawing callouts.
  4. Upload one engineering PDF. Pages are read locally. OCR handles image-only title blocks, and Local AI visually reviews enlarged drawing regions.
  5. Run the automatic checks. Keep the page open while the timer and activity messages show what is being reviewed.
  6. Confirm every finding. Use confidence, page preview, comments, and status controls to accept, correct, or mark false positives.
  7. Save or export. The latest five reviews remain in Local History when browser storage allows.

Important: Peer Review identifies potential visible inconsistencies. It does not certify engineering design or replace an engineer’s final review.

    Equipment checks

    These checks use only values that were detected or entered in the equipment table.

    Equipment identityMatches exact tags first, then compares the core equipment name. Short drawing labels can match longer schedule descriptions.Words such as system, package, assembly, equipment, and stand do not create a mismatch by themselves.
    Missing drawing calloutChecks whether a major equipment-list item has a matching numbered callout or equivalent visible equipment name.This rule runs only when at least 75% coverage and at least 10 main-equipment callouts were extracted.
    Duplicate and conflicting entriesChecks repeated tags and detected equipment values for conflicting descriptions or specifications.
    Detected specification fieldsCompares manufacturer, model, part number, quantity, voltage, phase, horsepower, amperage, flow, pressure, and connection sizes only when those columns were detected.
    Schedule cleanupRejects conduit, conductor, voltage-schedule, fittings, and responsibility-table rows that are not formal equipment-list items.
    Drawing coordinationReviews major equipment counts, labels, tanks, control-panel clearance, required valves/unions, drain routing, repeated dimensions, and inconsistent plan/elevation views.

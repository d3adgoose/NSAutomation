How to Use Database
  1. Add a PDF: choose or drag in a reusable PDF, then confirm the File Name and File Location.
  2. Set metadata: pick the Document Type, TOC Section, and Category before adding it to the library.
  3. Find files: open the Generic, Car Wash, or Transit Wash tables to browse saved PDFs by category.
  4. Format levels: use Format Levels to set TOC rows, parent rows, and whether the PDF name appears in the TOC.
  5. Use selected PDFs: select one or more PDFs to merge, remove, or send directly to Submittal or O&M.
